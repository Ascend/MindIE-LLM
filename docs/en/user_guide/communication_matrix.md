# Communication Matrix

The MindIE LLM communication matrix describes the open ports, transmission protocols used by the ports, and names, authentication modes, and functions of the network elements used for communication with the peer end through the ports.

> [!NOTE]
> For communication matrices related to datadist, HCCL, LCCL, and ATB, refer to the [CANN Communication Matrix](https://www.hiascend.com/document/detail/en/CANNCommunityEdition/latest/maintenref/refdoc/refer001.html).
