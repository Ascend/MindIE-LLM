# Security Hardening Precautions

When MindIE is used, the host runs the Linux operating system, and the inference accelerator card has its own smaller operating system. To ensure the security for both the host and device, you are advised to adhere to the security hardening recommendations provided. You need to review the network security hardening measures of the entire system based on your service requirements. You should perform related configurations according to the security policies of your organization, including but not limited to software versions, password complexity requirements, security configurations (protocols, cipher suites, and key lengths), permission configurations, and firewall settings. If necessary, refer to excellent hardening solutions in the industry and suggestions from security experts.
