# Enabling Docker Audit

The Docker daemon runs on the host with the root privilege. You are advised to configure an audit mechanism to monitor the running and usage status of the Docker daemon on the host. Once the Docker daemon encounters unauthorized attacks, the root cause of the attack event can be traced.

The following paths and files store important information related to containers. You are advised to configure the audit function for them.

- /var/lib/docker
- /etc/docker
- /etc/default/docker
- /etc/docker/daemon.json
- /usr/bin/docker-containerd
- /usr/bin/docker-runc
- docker.service
- docker.socket
- /usr/bin/docker

> [!NOTE]NOTE
>
> - The preceding directories are the default Docker installation directories. If a separate partition is created for Docker, use the actual paths.
> - If the audit function is enabled, a large number of log files will be generated. You need to dump the log files periodically, so partition the audit function separately.

1. (Ubuntu as an example) Install auditd required for enabling the audit mechanism.

    ```bash
    apt install -y auditd
    ```

2. Go to the `/etc/audit/` directory and add rules to the `audit.rules` file. Each rule occupies a line. The rule format is as follows. For details about the parameters in the rule, see [Table 1](#table1).

    ```bash
    -w file_path -k docker
    ```

    **Table 1** Parameter description <a id="table1"></a>

     |Parameter|Description|
     |--|--|
     |-w|File path filtering. *file_path* indicates the path of the file for which the audit rule is enabled. <ul><li>If *file_path* is `/usr/bin/docker`, the host audits the Docker daemon. </li><li>If *file_path* is `/etc/docker`, the host is enabled to audit Docker-related directories and key files.</li></ul>|
     |-k|Specifies keywords for string filtering.|

    > [!NOTE]NOTE
    > If the `/etc/audit/audit.rules` file contains "This file is automatically generated from /etc/audit/rules.d", the modification to the file is invalid. In this case, you need to modify the `/etc/audit/audit.rules` file for the modification to take effect. For example, if the OS is Ubuntu, modify the `/etc/audit/rules.d/audit.rules` file.

3. After the configuration is complete, restart the log daemon.

    ```bash
    service auditd restart
    ```
