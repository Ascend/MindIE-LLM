# Enabling TLS Authentication for TCP Remote Access

To prevent security risks, you are advised to use secure protocols, such as SSHv2, TLS1.2, TLS1.3, IPsec, SFTP, and SNMPv3.

If a container uses insecure protocols, such as Telnet, FTP, SSHv1.x, TFTP, SNMPv1, SNMPv2c, SSL2.0, SSL3.0, and TLS1.0, you are advised to disable them or replace them with secure protocols on condition that services are not affected.
