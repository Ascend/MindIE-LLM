# Other Security Hardening Measures

## (Optional) Key Update

If HTTPS is enabled, you need to periodically update the key. Therefore, plan the key update period properly.

## Risk of Information Leakage

To prevent information leakage during the communication between the service and client, you are advised to enable HTTPS communication. Also, enable HTTPS two-way authentication, encrypt the certificate private key using the tool provided by the service, and securely store the encrypted key.
