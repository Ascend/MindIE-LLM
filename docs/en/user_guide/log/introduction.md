# Log Reference

## Usage Instructions

Log operations are normalized. You can set logs of all MindIE components by using the following environment variables, as listed in [Table 1](#table1).

**Table  1**  Log settings  <a id="table1"></a>

| Environment Variable | Function |
|--|--|
| MINDIE_LOG_LEVEL | Sets the log level. For details, see [Setting the Log Level](setting_log_level.md). |
| MINDIE_LOG_TO_FILE | Specifies whether to write logs to files. For details, see [Setting the Log Display Mode](setting_log_display.md). |
| MINDIE_LOG_TO_STDOUT | Specifies whether to print logs. For details, see [Setting the Log Display Mode](setting_log_display.md). |
| MINDIE_LOG_PATH | Sets the log flush path. For details, see [Setting the Log Flush Path](setting_log_path.md). |
| MINDIE_LOG_VERBOSE | Specifies whether to print optional log information. For details, see [Configuring the Log Content](configuring_log_content.md). |
| MINDIE_LOG_ROTATE | Specifies whether to rotate logs. For details, see [Configuring Log Rotation](configuring_log_rotation.md). |
